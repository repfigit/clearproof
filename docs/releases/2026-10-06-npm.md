# Published package verification, October 6, 2026

The public npm registry returns 0.7.0 as `latest` for all five Clearproof
packages, which matches the source workspace version. They were published from
the `v0.7.0` GitHub release (tag at `bf62765`) by `release.yml` through npm
trusted publishing, and each one carries a signed SLSA provenance attestation.
This record supersedes the earlier 0.6.0 capture from the same day.

The [captured registry record](2026-10-06-npm.json) holds each package's
version, SHA-512 integrity and attestation URL. All five downloaded tarballs
matched their registry integrity values. A clean install of
`@clearproof/cli@0.7.0` and `@clearproof/proof@0.7.0` reported verified registry
signatures for every installed package, and `npm audit signatures` reported
verified attestations. This check does not establish production assurance.

The 0.7.0 SDK (`@clearproof/proof`) adds:

- shared field-element validation and generated `pilot-transfer-v3` signal
  constants;
- `verifyProof` reporting `isCompliant`/`sarReviewFlag` only for a valid proof.

The 0.7.0 packages also include:

- **`@clearproof/circuits`:** the `pilot-transfer-v3` source and the generated
  `pilot-profile.json`. Compatible compiled proving artifacts are still a
  separate requirement.
- **`@clearproof/cli`:** requires Node ≥22.12. Its archive includes the doctor,
  current inspection, authorization, observation, history review and report
  commands.

The Python package is not published to PyPI.

Recheck the registry and packed declarations before changing the public catalogue:

```bash
npm view @clearproof/proof versions --json --registry=https://registry.npmjs.org
npm view @clearproof/cli versions --json --registry=https://registry.npmjs.org
npm view @clearproof/content versions --json --registry=https://registry.npmjs.org
npm view @clearproof/contracts versions --json --registry=https://registry.npmjs.org
npm view @clearproof/circuits versions --json --registry=https://registry.npmjs.org
```

A workspace version bump or successful source build does not publish a package.
