# Published package verification, October 6, 2026

The public npm registry currently returns 0.6.0 for all five Clearproof packages.
Version 0.7.0 is the source workspace version and is not available in those
registry version inventories. Earlier 0.7.0 publication claims are superseded.
The [captured registry record](2026-10-06-npm.json) retains package versions,
SHA512 integrity and attestation URLs. All five downloaded tarballs matched their
registry integrity values. Registry metadata includes signatures/attestations;
this check does not independently establish production assurance.

The 0.6.0 SDK declaration exports `inspectCurrentProof`, whose response names
`pilot-transfer-v3` and eight-signal current inspection. It also exports the
legacy `generateProof`/`verifyProof`, observations, authorization and discovery
helpers described in the SDK guide. The 0.6.0 circuit package includes the
`pilot-transfer-v3` source; compatible compiled proving artifacts remain a
separate requirement. The CLI archive includes doctor, current inspection,
authorization, observations, history review and report commands.

Recheck the registry and packed declarations before changing the public catalogue:

```bash
npm view @clearproof/proof versions --json --registry=https://registry.npmjs.org
npm view @clearproof/cli versions --json --registry=https://registry.npmjs.org
npm view @clearproof/content versions --json --registry=https://registry.npmjs.org
npm view @clearproof/contracts versions --json --registry=https://registry.npmjs.org
npm view @clearproof/circuits versions --json --registry=https://registry.npmjs.org
```

A workspace version bump or successful source build does not publish a package.
