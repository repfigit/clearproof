The September 5 research reports linked from the [implementation plan](../plans/2026-09-05-adoption-pilot-implementation.md)
provide the rationale for the initial customer hypothesis. The plan's execution
log and current source/tests govern capability claims; the old research baseline
is not an implementation inventory. This packet adds no new market-size,
competitor-price or regulatory assertions.

The intended distribution model keeps the verifier, portable formats and local
simulator free, with proposed paid operational services. Apache-2.0 is the current
repository license. Source availability, release packaging and production
assurance are separate gates: do not describe unreleased source features as
already available in public npm 0.3.0 or promise a public repository link without
checking access. F4 customer access/agreement and F5 production readiness remain
outside local M0–M5 completion.
