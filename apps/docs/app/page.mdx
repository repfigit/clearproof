# clearproof

Privacy-focused evidence for crypto transfers.

clearproof is **pilot-stage software** for evaluating zero-knowledge checks, encrypted transfer information and EVM verification. A valid proof establishes an encoded statement; it does not by itself establish legal compliance.

**Checked September 5, 2026:** published npm packages are at **0.3.0**; the development checkout is **0.4.0**. The main GitHub repository is currently **private**. These docs describe development components and their limitations, which may differ from published packages.

- [Project status and planned work](/docs/status)
- [Installation and artifact requirements](/docs/quickstart)
- [Security and assurance limits](/docs/security)
- [Privacy and data minimization](/docs/gdpr)

Current circuits and contracts have not completed independent audits. Development proving artifacts are not suitable for production fund movement.
